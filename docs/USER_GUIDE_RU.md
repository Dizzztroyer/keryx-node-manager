# Keryx Node Manager — руководство пользователя

> Эта сборка находится на раннем этапе разработки (см. `PROJECT_STATUS.md`). Ниже описано, как
> пользоваться тем, что уже реально работает, и честно указано, чего пока нет.

## Установка

1. Скачайте `KeryxNodeManager-Setup-<версия>.exe` из `artifacts\` (после сборки — см.
   `docs/BUILD.md`, если вы собираете из исходников) или готовый релиз.
2. Запустите установщик, следуйте подсказкам. Никаких дополнительных прав администратора
   программа не запрашивает при обычном запуске.
3. Либо распакуйте `KeryxNodeManager-Portable-<версия>.zip` в любую папку и запустите
   `KeryxNodeManager.exe` — установка не требуется.

## Первый запуск

При первом запуске откроется мастер настройки (шаги описаны в `docs/ARCHITECTURE.md` и исходном
техническом задании). **В этой сборке реализована только основная оболочка приложения** —
дерево навигации, страница "Обзор" и страница "Видеокарты" — остальные шаги мастера (проверка
NVIDIA/WSL, выбор директорий, ввод адреса, запуск ноды/майнера) ещё не собраны в единый
поток; см. раздел "Чего пока нет" ниже.

## Что уже работает

- **Обзор** — показывает статус ноды/майнера (заглушка, пока не подключён реальный профиль
  запуска) и количество обнаруженных GPU.
- **Видеокарты** — реально опрашивает `nvidia-smi` (если программа запущена без `--mock`) и
  показывает каждую карту: имя, CUDA-индекс, UUID, объём видеопамяти, температуру, а также
  предпросмотр автоматического назначения tier'а (какая модель подойдёт этой карте) — это
  реальный расчёт по формулам из `KeryxNodeManager.Core`, а не заглушка.
- **Трей** — сворачивание в системный трей при закрытии окна, контекстное меню с пунктами
  "Открыть", "Выйти" (с подтверждением: закрыть только интерфейс или остановить всё).
- **Тестовый режим (`--mock`)** — запуск `KeryxNodeManager.exe --mock` подставляет три
  виртуальные видеокарты и имитацию процессов ноды/майнера, чтобы можно было посмотреть
  интерфейс без реального железа/Keryx-бинарников.

## Чего пока нет (важно понимать до начала использования)

Страницы "Модели", "Нода", "Майнер", "Логи", "Диагностика", "Настройки", "Обо программе" сейчас
показывают явную заглушку "ещё не реализовано в этой сборке" вместо содержимого — они **не**
притворяются рабочими. Реальный запуск/остановка `keryxd.exe`/`keryx-miner.exe` из интерфейса,
мастер первого запуска (проверка NVIDIA/WSL, выбор директорий), скачивание моделей, автозапуск с
Windows, установщик и portable-сборка как таковые — не протестированы на реальной Windows-машине
в этой сессии (только компиляция кода проверена). Точный список — `PROJECT_STATUS.md`.

## Как запустить node/miner вручную, пока страницы "Нода"/"Майнер" не собраны

До появления полноценного UI для этого — используйте официальные бинарники напрямую:

```powershell
# Нода
.\keryxd.exe

# Майнер (в отдельном окне/после того как нода готова)
.\keryx-miner.exe --mining-address keryx:ВАШ_АДРЕС
```

Подробности параметров — `docs/KERYX_RESEARCH.md`.

## Безопасность

Программа никогда не запрашивает seed-фразу или приватный ключ — только публичный адрес для
получения награды. Подробности — `docs/SECURITY.md`.

## Удаление

Через установщик — «Установка и удаление программ» Windows, как обычное приложение.
Portable-версию — просто удалите папку. Конфигурация хранится в
`%LocalAppData%\KeryxNodeManager\` — при обычном удалении программы она не трогается; если хотите
удалить её тоже, удалите эту папку вручную.
