# Диагностика проблем

**"nvidia-smi не найден"** на странице "Видеокарты" — установите/обновите драйвер NVIDIA
(nvidia.com/drivers). Программа не устанавливает драйверы сама и не должна — это отдельный шаг.

**Приложение не открывается повторно, ничего не происходит** — оно уже запущено и свёрнуто в
трей (значок рядом с часами). Программа поддерживает только один экземпляр одновременно
(защита от двойного запуска — брифом требовалось не дублировать управление процессами).

**Хочу увидеть интерфейс без реального железа/установленного Keryx** — запустите
`KeryxNodeManager.exe --mock` (см. `docs/USER_GUIDE_RU.md`).

**Где хранятся настройки** — `%LocalAppData%\KeryxNodeManager\settings.json`. Файл не трогать
руками без крайней необходимости; при повреждении программа создаёт `settings.json.bak` при
каждом сохранении — можно вручную переименовать `.bak` обратно в `.json`, если что-то пошло не
так.

**Не подключается к ноде** — по умолчанию майнер обращается к `127.0.0.1:22110` (mainnet).
Проверьте, что `keryxd.exe` запущен и слушает этот порт; подробности портов — в
`docs/KERYX_RESEARCH.md` §5.

**Нет пункта "Модели"/"Нода"/"Майнер" с реальным содержимым** — эти страницы в текущей сборке
являются заглушками (см. `PROJECT_STATUS.md`). Это не баг — это честно обозначенный
незавершённый функционал.

Если что-то из вышеперечисленного не помогло — соберите диагностический пакет (когда страница
"Диагностика" будет реализована) или, пока её нет, соберите вручную: вывод
`nvidia-smi`, содержимое `%LocalAppData%\KeryxNodeManager\logs\` (если есть), версию Windows
(`winver`), версию драйвера NVIDIA.
